# Skills Organization

This directory contains specialized skills organized by domain and use case.

## Directory Structure

### 📐 Architecture (`architecture/`)
System design patterns and architectural approaches for building scalable applications.

- **architecture-patterns** - General architectural patterns and best practices
- **microservices-patterns** - Patterns for microservices architecture
- **cqrs-implementation** - Command Query Responsibility Segregation implementation
- **saga-orchestration** - Saga pattern for distributed transactions

### 🔌 API & Backend (`api-and-backend/`)
Skills related to API design, backend development, and workflow orchestration.

- **api-design-principles** - RESTful API design and best practices
- **workflow-orchestration-patterns** - Patterns for workflow management
- **temporal-python-testing** - Testing strategies for Temporal workflows in Python

### ☁️ Cloud & Infrastructure (`cloud-and-infrastructure/`)
Cloud architecture, infrastructure as code, and cost optimization.

- **cost-optimization** - Cloud cost optimization strategies
- **hybrid-cloud-networking** - Hybrid cloud networking patterns
- **multi-cloud-architecture** - Multi-cloud design and deployment
- **terraform-module-library** - Terraform modules and IaC patterns

### 🕸️ Service Mesh (`service-mesh/`)
Service mesh implementations, traffic management, and observability.

- **istio-traffic-management** - Istio traffic control and routing
- **linkerd-patterns** - Linkerd service mesh patterns
- **mtls-configuration** - Mutual TLS configuration and security
- **service-mesh-observability** - Observability in service mesh environments

### 💾 Data & Storage (`data-and-storage/`)
Event sourcing, data modeling, and database design patterns.

- **event-store-design** - Event store implementation and design
- **projection-patterns** - Event projection and read model patterns
- **postgresql-table-design** - PostgreSQL schema and table design

### 🎨 UI/UX (`ui-ux/`)
User interface and user experience design skills.

- **impeccable-full** - Complete UI/UX design toolkit
- **ui-ux-pro-max** - Advanced UI/UX patterns and practices

## Usage

To activate a skill in your Kiro session, reference it using the disclose_context tool or by mentioning its domain in your request.

## Adding New Skills

When adding new skills, place them in the appropriate category directory. If a skill doesn't fit existing categories, consider creating a new category directory with a descriptive name.
